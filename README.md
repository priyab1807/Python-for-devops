# Python-for-devops
A hands-on repository for learning Python with a DevOps/SRE focus.
The goal is to learn Python by building scripts and automation that are commonly useful in DevOps, including:

1. File and directory automation
2. Linux system administration
3. Working with processes
4. HTTP APIs
5. JSON/YAML
6. AWS/cloud automation
7.Docker and Kubernetes automation
8. CI/CD automation
9. Monitoring and log processing

📋 Prerequisites

You should have:
1. Ubuntu/Linux environment
2. Basic Linux command-line knowledge
3. Git
4. Basic programming knowledge is helpful, but not required
