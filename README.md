# Python-for-devops
A hands-on repository for learning Python with a DevOps/SRE focus.
The goal is to learn Python by building scripts and automation that are commonly useful in DevOps, including:

File and directory automation
Linux system administration
Working with processes
HTTP APIs
JSON/YAML
AWS/cloud automation
Docker and Kubernetes automation
CI/CD automation
Monitoring and log processing

📋 Prerequisites
You should have:
Ubuntu/Linux environment
Basic Linux command-line knowledge
Git
Basic programming knowledge is helpful, but not required
